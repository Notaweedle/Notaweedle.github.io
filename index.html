Projects

Things I've built

01 · C++

nu — 2D Game Engine

A game engine written from scratch in modern C++ on SDL3: renderer, input, text rendering and a file system module, refactored into an actor–component architecture with a string-keyed factory, JSON scene serialization with prefab-style prototypes, Box2D physics, sprite animation and Tiled tilemaps. Two games run on it, including a dungeon crawler with a skeleton boss.

C++ SDL3 Box2D JSON Design Patterns
Source on GitHub ↗

02 · C# · Team

Minecraft Server Web Panel

A Blazor web app for managing a Minecraft server. Users sign up and log in through ASP.NET Core Identity, and server commands go out over RCON through a Node.js bridge. Data is stored with Entity Framework Core migrations.

C# Blazor ASP.NET Core EF Core Node.js
Source on GitHub ↗

03 · Java

Pokédex Tracker

A JavaFX desktop app for tracking Pokémon and building teams, pulling live data from PokéAPI. Search by name or Dex number with autocomplete, plan six-slot teams with moves, natures and IV/EV validation, and everything saves to JSON between sessions. Built with Maven and tested with JUnit 5.

Java JavaFX REST API Gson JUnit
Source on GitHub ↗

04 · Python · Team

Rat Rant — Voice Commands

A cross-platform (Windows and Linux) app that controls your computer by voice: volume, mic mute, brightness, media playback, window management, app launching and custom commands. Built as a student team over weekly Scrum sprints, ending in a live class demo.

Python Speech Recognition Scrum
Source on GitHub ↗

Game Jams & Unity Games

Three playable games published on itch.io: StatMaxxer, a survival game for the Neumont Winter Game Jam 2026; Speed Waggon, a platformer for the Summer Game Jam 2026 (both built in 72 hours); and Tanking It, a Unity tank game with turrets, pickups, health, scoring and a full menu flow.
